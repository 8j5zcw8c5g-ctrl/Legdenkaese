# 🧀 Leg den Käse

Comedy-Flirt-Simulation mit KI-Figuren – als Web-App und als iPhone-App (Capacitor).

- **Spielen im Browser:** `index.html` (über GitHub Pages)
- **Einstellungen:** `config.js`
- **KI-Server:** `worker.js` (Cloudflare Worker, ruft die Claude API auf – der API-Schlüssel liegt nur dort)
- **iPhone-App bauen:** `codemagic.yaml` (Codemagic baut, signiert und lädt zu TestFlight hoch)
- **Datenschutz / Support:** `datenschutz.html`, `support.html`
